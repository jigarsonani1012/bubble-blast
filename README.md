# 🫧 Bubble Blast — Match & Pop Arcade Challenge

> An action-packed, vibrant HTML5 Arcade Bubble Shooter built with modern Vanilla JavaScript, Canvas 2D, GSAP animations, and Web Audio API.

[![License: MIT](https://img.shields.io/badge/License-MIT-gold.svg)](LICENSE)
[![HTML5 / CSS3 / ES6+](https://img.shields.io/badge/Tech-HTML5%20%7C%20CSS3%20%7C%20ES6%2B-brightgreen.svg)]()
[![GSAP](https://img.shields.io/badge/GSAP-3.12-blue.svg)](https://greensock.com/gsap/)

---

## ✨ Features

- **🎯 Match-3 Hexagonal Grid Engine**:
  - Precision collision detection, bounce mechanics, and match-3 popping logic.
- **💣 Special Power-ups & Bomb Bubbles**:
  - Explosive bomb bubbles, color rainbow wildcards, and floating detachment physics.
- **✨ GSAP Powered Visual Effects**:
  - Smooth particle pops, level-up banners, score popups, and UI transitions.
- **🔊 Web Audio API Sound & Volume Control**:
  - Synthetic sound FX for shooting, popping, explosions, and volume sliders.
- **🏆 Progressive Levels & High Score Saving**:
  - Escalating difficulty per level, progress bar tracking, persistent best scores.

## 🚀 Quick Start

No build tools or bundlers required!

### Local Development / Running
1. Clone the repository:
   ```bash
   git clone https://github.com/jigarsonani1012/bubble-blast.git
   cd bubble-blast
   ```
2. Open `index.html` using a local web server (e.g., VS Code Live Server, `npx serve`, or `python -m http.server`).
3. Open `http://localhost:8000` in your web browser.

## 🕹️ Controls

| Control | Action |
| :--- | :--- |
| **Mouse / Touch Drag** | Aim trajectory line |
| **Left Click / Release Touch** | Launch bubble towards target |
| **☰ Menu Toggle** | Pause game and open side drawer menu |
| **🔊 Sound Icon / Slider** | Toggle or adjust audio volume |
